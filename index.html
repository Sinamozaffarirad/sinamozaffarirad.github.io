Projects

Architecture, co-design and embedded

Application mapping on a shared bus vs a 4×4 mesh NoC

Timed Petri nets · MATLAB · Hardware/Software Co-Design course

One application mapped onto 16 processing elements and modelled on both interconnects, adding communication delay and then PE and link contention. With delay only, the NoC finished first (33 vs 35 time units). With contention, my mapping on the NoC was slower than the bus (37 vs 35), because XY routes shared links.

FFT8: static vs dynamic dataflow scheduling

C++ · dataflow · Hardware/Software Co-Design course

An 8-point radix-2 FFT built as four dataflow actors, run with a static schedule, a FIFO-driven single-thread scheduler and one thread per actor. All three give the same verified output.
